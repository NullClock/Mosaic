# Mosáic

> For now, Mosáic is just a proof of concept music player UI, and I'm not sure if I will turn it into a fullstack application with real music streaming.

Mosáic is (soon to be) a next-generation web music player with an intuitive UI similar to Apple Music's, word-by-word/line-by-line time synced lyrics, and an immense music catalog derrived from YouTube Music, streamed from a local (or remote, if using for school/filter evasion) proxy and into the web player.

Basically, a spiritual successor to BitChord Web.
